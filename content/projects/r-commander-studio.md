A standalone, VS Code-style **R and R Markdown IDE** with offline Monaco Editor, all **371 bilingual (`ES` / `EN`) R Commander & TeachStat dialogs**, live R LSP diagnostics and hover documentation, interactive `View(df)` Table Viewer, `arf` and `R` terminals, a rich Markdown Viewer, and a zero-bloat local bridge to **[NoteComplete](https://github.com/Emefedez/NoteComplete)**.

Also available as a VS Code extension: **[r-commander-in-vscode](https://github.com/Emefedez/r-commander-in-vscode)**.

**Context:**

I don't really like the provided tool to use R for my university, I first made an extension for VSCode ([r-commander-in-vscode](https://github.com/Emefedez/r-commander-in-vscode)) and used AI to turn it into a standalone tool.
